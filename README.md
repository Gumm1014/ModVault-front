# ModVault – Frontend
Plataforma web de mods de videojuegos, desarrollada para la Trayectoria Pedagógica Interdisciplinaria (TPI) del Colegio Técnico Provincial Olga B. de Arko.

## Tecnologías
React, Vite, Wouter y Axios.

## Instalación y ejecución
npm install
npm run dev
